## 2. Claims Strictly Prohibited in All TerraTwin Materials

1. **Prohibited:** *"TerraTwin discovers field-certified NASA landing or training sites automatically."*
   - **Required Truthful Wording:** Live-grid discovery cells are unverified remote-sensing screening leads (`isVerified: false`) requiring independent high-resolution orbital and in-situ field validation.
2. **Prohibited:** *"Lake Salda returns a high geological similarity score in a live automated grid scan."*
   - **Required Truthful Wording:** In a live 2×2 grid scan under `geological-research`, Lake Salda returns `15%` coverage (`score: null`) because Macrostrat’s global map lists `"Pliocene undifferentiated"`; it scores `65.0%` (`45%` coverage) in a live `rover-testing` scan, and `81.1%`–`87.1%` in the curated Global Atlas where peer-reviewed carbonate field data are cataloged.
3. **Prohibited:** *"The 31 Global Discovery Atlas sites were automatically discovered by a global grid sweep."*
   - **Required Truthful Wording:** The 31 Global Discovery Atlas sites (8 canonical benchmarks + 23 under-explored candidates) are scientifically curated from peer-reviewed planetary analog literature and calibrated with NASA/ESA datasets.
4. **Prohibited:** *"Completing a research task in the Research Workspace marks a candidate as scientifically verified."*
   - **Required Truthful Wording:** Task status tracks workflow progress only; `observationStatus` remains `"recommended-not-completed"` and never upgrades `isVerified`.
5. **Prohibited:** *"TerraTwin is endorsed or certified by NASA."*
   - **Required Truthful Wording:** TerraTwin is an independent hackathon project built by Team HEXARCHY for the NASA International Space Apps Challenge using open NASA, ESA, USGS, Copernicus, and Macrostrat datasets.
